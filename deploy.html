오늘 목표는 하나입니다. 내 주소가 생기는 것.

1. 배포가 뭔데?

지금 내 index.html은 내 컴퓨터 안에만 있습니다. 그래서 나만 볼 수 있습니다.

인터넷에 올리면 주소가 생깁니다. 그 주소를 아는 사람은 누구나 열 수 있습니다. 폰으로도, 친구 PC로도요.

그게 배포입니다. 오늘 하는 건 이것 하나입니다.

서버를 빌리거나 도메인(.com 같은 거)을 사는 건 오늘 하지 않습니다. 돈도 안 듭니다.

2. Vercel과 Render, 뭐가 다른가

둘 다 무료로 올릴 수 있는 서비스입니다. 경쟁 관계가 아니라 용도가 다릅니다.

Vercel ← 오늘 쓸 것Render
뭘 올리나완성된 웹페이지계속 돌아야 하는 서버
올리는 방법드래그 · 터미널 · GitHubGitHub 연결만
GitHub 계정없어도 된다반드시 필요
무료로 쓰면개인·비상업용만15분 쉬면 잠든다

우리가 만든 건 index.html 파일 하나입니다. 서버가 필요 없습니다. 그래서 Vercel입니다.

Render는 나중에 로그인 기능이나 데이터베이스를 붙일 때 씁니다. 오늘은 이름만 알아두면 됩니다.

3. Vercel 계정 만들기

  1. vercel.com 에 들어갑니다.
  2. Sign Up 을 누릅니다.
  3. GitHub 계정이 있으면 Continue with GitHub, 없으면 이메일로 가입합니다.

알아둘 것

  • 무료입니다. 카드 번호 넣는 곳이 없습니다.
  • 약관상 만 16세 이상이어야 합니다.
  • 계정과 비밀번호는 다른 사람과 공유하지 않습니다.
  • 무료 플랜은 개인·학습용입니다. 돈 버는 서비스에는 쓸 수 없습니다.
GitHub 계정이 있으면 그걸로 가입하는 게 좋습니다. 나중에 5번 단계가 훨씬 편해집니다.

4. 드래그 한 번으로 올리기 ← 오늘의 핵심

준비물은 index.html이 들어 있는 내 폴더 하나입니다.

  1. 브라우저에서 vercel.com/drop 을 엽니다. (로그인 상태여야 합니다)
  2. 내 폴더를 통째로 끌어다 놓습니다.
    파일 탐색기에서 폴더를 잡고 브라우저 화면 위로 드래그하면 됩니다. 폴더 안의 index.html을 Vercel이 알아서 찾습니다.
  3. 프로젝트 이름을 물어보면 짓습니다. 예: chulsoo-lunch
    이 이름이 주소가 됩니다. 한글은 피하고 영문·숫자로 짓습니다.
  4. Deploy 를 누릅니다.
이렇게 나오면 성공 — 몇 초 뒤에 주소가 나옵니다. 
https://chulsoo-lunch.vercel.app
그 주소를 눌러서 내 페이지가 열리면 끝입니다.

꼭 해보기

  • 폰으로 열어보세요. 주소를 카톡으로 나한테 보내서 눌러보면 됩니다.
  • 옆 사람과 주소를 교환해서 서로 열어봅니다.
여기까지가 오늘의 목표입니다. 주소가 나왔으면 성공입니다.

5. 고친 걸 다시 올리려면

드래그는 할 때마다 새 프로젝트, 새 주소가 생깁니다.
방금 만든 주소가 갱신되는 게 아닙니다. 계속 고칠 거면 주소가 계속 바뀌어서 불편합니다.

방법 A · 터미널에서 올리기

어제 Node.js를 깔았으면 바로 됩니다. 내 폴더에서 터미널을 열고:

npx vercel --prod

처음 실행하면 몇 가지를 물어봅니다. 거의 다 Enter만 치면 됩니다.

물어보는 것답
Set up and deploy?Y
Which scope?Enter (내 계정)
Link to existing project?N (처음이면)
What's your project's name?이름 입력
In which directory is your code located?Enter (./)
다음부터는 npx vercel --prod 한 줄이면 같은 주소가 갱신됩니다.
터미널 여는 법이 기억 안 나면: 파일 탐색기에서 내 폴더를 연 다음, 위쪽 주소 표시줄에 powershell 치고 Enter.

방법 B · GitHub에 연결하기

가장 편한 방법입니다. 한 번만 연결해두면 그 뒤로는 git push 만으로 자동 배포됩니다.

  1. GitHub에 내 저장소를 만듭니다.
  2. Vercel 프로젝트에서 Settings → Git 으로 들어갑니다.
  3. 내 저장소를 연결합니다.

이미 만든 프로젝트에 나중에 붙여도 됩니다. 주소는 그대로 유지됩니다.

저장소는 자기 개인 GitHub 계정에 만드세요.
학교 조직(Organization) 계정의 비공개 저장소는 무료 플랜에서 배포가 안 됩니다. 개인 계정이면 비공개여도 문제없습니다.

안 될 때

드래그했는데 아무 일도 안 일어남

로그인이 안 된 상태입니다. vercel.com에서 먼저 로그인하세요.

주소는 나왔는데 화면이 하얗게 나옴

폴더 안에 index.html이 있는지 확인하세요. 파일 이름이 정확히 index.html이어야 합니다. index.html.txt로 저장돼 있는 경우가 종종 있습니다.

페이지는 열리는데 내가 바꾼 게 안 보임

옛날 폴더를 올린 겁니다. 내가 수정하고 저장한 그 폴더가 맞는지 확인하세요. 브라우저에서 Ctrl + Shift + R 로 강력 새로고침도 해보세요.

npx vercel 이 안 먹힘

어제 깐 Node.js가 있어야 합니다. 터미널에서 node --version 이 나오는지 먼저 확인하세요.

가입할 때 나이 제한에 걸림

Vercel은 만 16세 이상입니다. 걸리면 손을 드세요. 옆 사람 화면으로 같이 보면 됩니다.

오늘 한 것 
1. vercel.com 가입                  (무료, 카드 없음)
2. vercel.com/drop 에 폴더 드래그
3. Deploy → 주소 생김
4. 폰으로 열어보기                   ← 여기까지가 목표
5. (도전) npx vercel --prod 로 갱신
6. (도전) GitHub 연결해서 자동 배포
주소가 하나 생겼으면 오늘은 성공입니다.
