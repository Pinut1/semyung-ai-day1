1. 준비물: ChatGPT 계정

우리가 쓸 도구는 Codex CLI 하나입니다. OpenAI에서 만든 겁니다.

필요한 건 ChatGPT 계정 하나뿐입니다.

  • 무료 계정으로 됩니다. 결제 안 해도 됩니다.
  • 계정이 없으면 chatgpt.com에서 가입하세요. 이메일 인증까지 하면 끝입니다.
  • 이미 쓰고 있으면 로그인만 되는지 확인하면 됩니다.
무료 플랜은 하루에 쓸 수 있는 양이 정해져 있습니다.
다 쓰면 잠깐 못 쓰게 됩니다. 그때는 시간을 좀 두고 다시 하거나 VS Code에서 직접 고치면 됩니다.
그러니까 아무 말이나 계속 시키지 말고, 필요한 것만 시키세요.

2. 터미널 열기

터미널은 글자로 컴퓨터에 명령하는 창입니다. 검은 창 나온다고 겁먹지 마세요.

  1. 키보드 왼쪽 아래 윈도우 키를 누릅니다.
  2. 그냥 powershell 이라고 칩니다.
  3. Windows PowerShell을 클릭합니다.
이렇게 나오면 성공 
PS C:\Users\내이름>
이 PS 줄이 "명령을 기다리는 중"이라는 뜻입니다.

알아두면 편한 것

  • 붙여넣기는 마우스 오른쪽 클릭 한 번
  • 잘못 쳤으면 Enter 치고 다시 치면 됩니다. 망가지지 않습니다.
  • 위쪽 방향키 ↑ 를 누르면 방금 친 명령이 다시 나옵니다.

3. Node.js 확인 / 설치

AI CLI를 깔려면 Node.js가 먼저 있어야 합니다. 확인부터 합니다.

node --version
이렇게 나오면 성공 — v 뒤 숫자가 22 이상이면 됩니다. 
v22.14.0
바로 4번으로 넘어가세요.
이렇게 나오면 Node.js가 없는 겁니다 
node : 'node' 용어가 cmdlet, 함수, 스크립트 파일 또는
실행할 수 있는 프로그램 이름으로 인식되지 않습니다.

없을 때만: Node.js 설치

  1. 브라우저에서 nodejs.org 접속
  2. 초록 버튼 두 개 중 LTS라고 써 있는 쪽 클릭 (다른 쪽 누르지 마세요)
  3. 받아진 파일 두 번 클릭
  4. Next → Next → Install 만 계속 누름. 아무것도 바꿀 필요 없습니다.
  5. Finish
설치 끝나면 터미널 창을 완전히 닫고 새로 여세요.
안 그러면 방금 깐 Node.js를 컴퓨터가 못 찾습니다. 이거 안 해서 막히는 사람이 제일 많습니다.

4. AI CLI 설치

터미널에 이렇게 치고 Enter:

npm install -g @openai/codex

명령어 뜻

  • npm — Node.js에 딸려 오는 설치 담당 프로그램
  • install — 설치해라
  • -g — 이 컴퓨터 어디서든 쓸 수 있게 (global)
  • @openai/codex — 설치할 물건 이름
이렇게 나오면 성공 — 글자가 주르륵 올라가다 멈추고 PS 줄이 다시 나옵니다. 
added 1 package in 8s

PS C:\Users\내이름>
1~2분 걸릴 수 있으니 기다리세요. 노란 글씨(warn)는 경고일 뿐 오류가 아닙니다.
이름을 정확히 쳐야 합니다 
npm install -g codex           ✕  @openai/ 빠짐. 전혀 다른 게 깔립니다.
npm install -g @openai/codex   ○
@openai/를 빼먹는 게 제일 흔한 실수입니다.

5. 설치 확인

codex --version
버전 번호가 찍히면 설치 완료입니다. 숫자는 사람마다 다릅니다. 
codex-cli 0.1.2
'codex' 용어가 ... 인식되지 않습니다 가 나오면 터미널을 닫고 새로 열어서 다시 해보세요. 그래도 안 되면 오류 해결 3번.

6. 내 폴더로 이동 ← 제일 헷갈리는 부분

AI CLI는 지금 있는 폴더의 파일만 건드립니다. 내 index.html이 있는 폴더로 먼저 가야 합니다.

쉬운 방법 (이거 쓰세요)

  1. 파일 탐색기에서 내 작업 폴더를 엽니다. (index.html이 보이는 그 폴더)
  2. 위쪽 주소 표시줄을 클릭합니다. 파랗게 선택됩니다.
  3. 거기에 powershell 치고 Enter.
그 폴더에서 바로 터미널이 열립니다. 이동 끝. 7번으로 가세요.

직접 이동하는 방법

cd = change directory, 폴더 바꾸기

cd "C:\Users\내이름\Documents\김철수_점심추천기"
  • 경로에 띄어쓰기나 한글이 있으면 반드시 큰따옴표 " "로 감싸세요.
  • 경로는 탐색기 주소 표시줄에서 복사(Ctrl+C)해서 터미널에 오른쪽 클릭으로 붙여넣으세요. 직접 타이핑하지 마세요.

제대로 왔는지 확인

dir

index.html이 목록에 보이면 맞게 온 겁니다. 안 보이면 폴더를 잘못 찾은 겁니다.

7. 실행하고 로그인

codex

처음 실행할 때만

화면에 로그인 방법을 고르라고 나옵니다. Sign in with ChatGPT를 방향키 ↑ ↓로 고르고 Enter.

브라우저가 저절로 열립니다. 내 ChatGPT 계정으로 로그인하고 허용을 누릅니다. 로그인됐다는 문구가 나오면 브라우저를 닫고 터미널로 돌아옵니다.

결제하라는 화면이 나오면 건너뛰세요. 무료 계정으로 됩니다.
이렇게 나오면 성공 — 아래쪽에 입력창이 생깁니다. 이제 한국어로 말하면 됩니다. 
› 무엇을 도와드릴까요?
로그인은 처음 한 번만 합니다.

8. 첫 명령 시켜보기

욕심내지 말고 딱 한 줄만 시킵니다.

index.html 제목을 점심 추천기로 바꿔줘
그다음 크롬으로 가서 F5(새로고침)를 누르세요.
AI가 "바꿨습니다"라고 말해도 화면으로 확인하기 전까지는 안 된 겁니다. AI 말이 아니라 내 화면이 기준입니다.

확인할 것

  • 제목이 진짜 바뀌었나?
  • 추천 버튼이 아직 잘 눌리나?
  • 내가 아까 바꿔둔 다른 내용이 그대로 있나?

끄는 법: 터미널에서 Ctrl + C를 두 번 누르면 나갑니다.

오류 해결

1. npm ... 스크립트를 실행할 수 없으므로

윈도우가 보안 때문에 막은 겁니다. 한 번만 풀어주면 됩니다.

Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

Y 치고 Enter. 그다음 4번부터 다시.

2. EACCES / Access is denied / 권한 오류

윈도우 키 → powershell 검색 → 오른쪽 클릭 → 관리자 권한으로 실행

3. 설치는 됐다는데 codex를 못 찾음

  1. 터미널 창을 완전히 닫고 새로 엽니다. (이걸로 대부분 해결)
  2. 그래도 안 되면 진짜 깔렸는지 확인: 
    npm list -g --depth=0
    목록에 @openai/codex가 있으면 깔린 겁니다. 없으면 4번 다시.
  3. 목록엔 있는데 실행이 안 되면 손을 드세요. 혼자 붙잡지 마세요.

4. 로그인이 안 됨 / 결제하라고 나옴

결제 화면은 건너뛰면 됩니다. 무료 계정으로 쓸 수 있습니다.

그래도 안 되면 순서대로 확인하세요.

  1. 브라우저에서 chatgpt.com에 로그인이 되는지 먼저 확인
  2. 가입할 때 온 이메일 인증을 안 했으면 그것부터
  3. 학교 계정 말고 개인 계정으로 시도

4-1. 사용량을 다 썼다고 나옴

무료 플랜은 하루에 쓸 수 있는 양이 정해져 있습니다. 다 쓴 겁니다.

  • 시간을 좀 두고 다시 시도하세요.
  • 그동안은 VS Code에서 직접 고치면 됩니다. 실습은 계속할 수 있습니다.
  • 다음부터는 한 번에 하나씩, 필요한 것만 시키세요.

5. 브라우저가 안 열림

터미널에 주소가 같이 찍혀 있습니다. 드래그해서 복사하고 크롬 주소창에 직접 붙여넣으세요.

6. AI가 엉뚱한 파일을 고침 / 아무것도 못 찾음

폴더를 잘못 잡은 겁니다. dir을 쳐서 index.html이 보이는지 확인하고, 안 보이면 6번으로 돌아가세요.

7. 내가 바꾼 게 사라짐

AI한테 그대로 말하면 됩니다.

내가 바꿔둔 제목이 원래대로 돌아갔어. 그 부분만 되돌려줘.
혼자 5분 이상 붙잡지 마세요.
빨간색으로 표시하거나 손을 드세요. 설치가 안 끝나도 index.html 실습은 먼저 시작합니다. VS Code로 직접 고치면 됩니다.
